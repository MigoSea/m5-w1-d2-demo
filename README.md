# m5-w1-d2-demo: React State and Events (Week 1 Day 2)

This repository contains the completed in-class demo exercises for Westcliff University WEB 403/603 - Week 1 Day 2.

## Demos Overview

- **Demo 1:** `Car` Class Component with multiple state variables (`brand`, `model`, `color`, `year`) and rendering with `this.state`.
- **Demo 2:** State mutation with `setState` using an arrow function method (`changeColor`), updating the color from red to blue dynamically via button click without reloading the page.
- **Demo 3:** Event handling with functional components (`clickbutton` function triggering an `alert`).
- **Demo 4:** Converting functional event handlers into a Class Component (`Football` with a `shoot()` method).
- **Demo 5:** Binding and scoping of `this` using arrow function class properties (`shoot = () => { alert(this); }`), demonstrating how `this` refers to the React component instance.
